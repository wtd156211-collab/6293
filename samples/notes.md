# 现场记录：凹多边形漏一块，边缘还发毛

时间：2026-09-28
在场：老周、小林

自己按扫描线写的那版，先拿 L 形试：凹角那一行起就少填一片，越往下缺口越宽；
换 U 形，两个齿之间的空档连边缘一起歪掉，斜边那几行更怪——同一份数据前后两次
跑出来的像素能差一列，看着像边缘发毛。坐标全换成整数之后照样如此。

当场没吵出结论的几个点：

- 顶点正好压在扫描线上的行，这一行到底算不算？梳齿形的每个极值点都落在线上。
- 水平边所在的那几行：有时整行消失，有时又多出一行。
- 一个像素都不到的细斜条：整行全空或者连成一坨，两种都出现过。
- 孔是另一条轮廓，方向反过来写会不会变成实心？

最后商定：口径按 README 定死（填充规则、边界像素、精确比较），结果用
`samples/expected/` 逐字节核；先把「哪些像素算」钉死，再去谈快不快。
